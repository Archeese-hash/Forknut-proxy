# Forknut Proxy — Bolt.new package

Import this folder into Bolt.new.

Then paste the contents of `BOLT_PROMPT.md` into Bolt. It tells Bolt how to turn this branded frontend into a real Scramjet/Wisp deployment.

The starter intentionally does not pretend that a static HTML file is a proxy: the server-side Scramjet/Wisp transport must be installed and running for proxying to work.
